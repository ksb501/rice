# 🌾 꼬마 농부의 황금벼 키우기 (초등 벼의 한살이 교육용 웹앱)

초등학교 저학년(1~2학년) 및 중학년(3~4학년) 어린이들이 직관적으로 재미있게 즐길 수 있도록 제작된 인터랙티브 교육용 웹 애플리케이션입니다.

두피디아(Doopedia) 초등 과학 교육 영상 **「쌀은 이렇게 자라요! 벼의 한살이」**의 단계에 맞추어 복잡한 인터페이스를 걷어내고, 화면 상단의 불필요한 빈 공간을 없애 메인 화면에서 벼의 성장을 한눈에 볼 수 있도록 컴팩트하고 알차게 개편하였습니다.

---

## 🌟 벼의 한살이 6단계 (두피디아 초등 과학 교육과정)

1. **1단계: 볍씨 (씨앗과 싹 트기 - 4월)**
   - 작은 볍씨를 따뜻한 물과 햇빛, 농부의 사랑으로 보살펴 귀여운 연두빛 싹을 틔웁니다.
2. **2단계: 어린 모 (모판 육묘와 모내기 - 5월)**
   - 비닐하우스 모판에서 자란 튼튼한 '모'를 찰랑찰랑 물 찬 논에 줄 맞춰 심는 모내기를 체험합니다.
3. **3단계: 여름 벼 (새끼치기와 생태농법 - 6~7월)**
   - 모 한 포기에서 여러 줄기가 불어나는 **분얼(새끼치기)**을 관찰하고, 친환경 **오리와 우렁이**로 잡초와 벌레를 자연 친화적으로 해결합니다.
4. **4단계: 벼꽃과 이삭 패기 (출수 - 8월)**
   - 하얗고 작은 벼꽃이 피고 고개 숙인 초록색 이삭이 나오는 신비로운 순간을 관찰합니다.
5. **5단계: 황금 벼로 익어가기 (등숙 & 허수아비 탭 - 9월)**
   - 낟알이 탐스러운 황금빛으로 물드는 등숙기! 참새 떼가 날아올 때 **허수아비를 연속 탭**하여 참새를 쫓고 폭풍 성장을 돕습니다.
6. **6단계: 수확과 쌀이 되는 과정 (도정과 밥 - 10월)**
   - 벼 베기 & 탈곡 ➔ 1차 도정으로 왕겨(겉껍질)를 벗겨 **[현미]** 관찰 ➔ 2차 도정으로 쌀겨(속껍질)를 깎아 하얀 **[백미(쌀)]** 완성 ➔ 가마솥에 뜸 들여 따끈따끈 윤기 나는 쌀밥 한 그릇 완성!

## 🛠️ 하단 7대 액션 도구바 (직관적인 인터랙션)

화면 하단에 언제든 클릭할 수 있는 7가지 친환경 도구가 마련되어 있습니다:
- 💧 **물주기**: 찰방찰방 시원한 논물을 대어 벼의 갈증 해소
- ☀️ **햇빛쬐기**: 영롱한 하프 소리와 함께 따스한 햇살 광합성
- 🤲 **농부의 손길**: 사랑 가득 쓰다듬기와 칭찬으로 벼를 행복하게 보살피기
- 🦆 **오리농법**: 귀여운 오리들이 논물 위를 꽥꽥 헤엄치며 벌레와 잡초를 냠냠!
- 🐌 **우렁이농법**: 친환경 왕우렁이 군단이 논바닥을 기어가며 잡초를 아삭아삭 먹방!
- 🧑‍🌾 **허수아비**: 춤추며 방울을 흔들어 참새 떼를 쫓고 황금빛 에너지 폭풍 가속!
- 🚪 **중간 물 떼기**: 논바닥에 살짝 바람을 통하게 하여 뿌리를 땅속 깊이 튼튼하게 내리기
